Architecture
  • Algorithm: Multinomial Logistic Regression (lbfgs, max_iter=1000)
  • Multiclass: Softmax — P(y=k) = e^z_k / Σ e^z_j
  • Pipeline: StandardScaler → LogisticRegression
  • Dataset: 2,200 samples × 22 balanced crops (100 each)
  • Split: 80% Train (1,760) / 20% Test (440)
  • Layer Architecture:
    Layer 1: Geographic Intelligence (Region/State/District)
    Layer 2: Live Climate (Open-Meteo API, display only)
    Layer 3: ML Model (7-feature soil/climate profile from dataset)
